# SIGNAL 设计规范

博客的视觉主题叫 SIGNAL：把博客当成一台调试器，「从噪声里找信号」。
这一页记录已经定下来的规则，以后加页面、加组件时照着做，避免各写各的。

样式都在 `source/_data/signal-*.styl`：

| 文件 | 管什么 |
| --- | --- |
| `signal-base.styl` | 颜色与字体变量、页头、页脚（Coda）、侧栏目录、浮动按钮 |
| `signal-home.styl` | 首页各区块 |
| `signal-article.styl` | 文章页：标题、正文、代码块、评论 |
| `signal-pages.styl` | 归档、分类、标签、学习路线、404 |

样式写在 `@css { }` 里，否则 Stylus 会改写 `min()`、`max()`、`clamp()`。

## 颜色

只用 `:root` 里的变量，不在组件里写新的颜色值。

| 变量 | 值 | 用途 |
| --- | --- | --- |
| `--void` | `#05060b` | 页面底色 |
| `--ink` / `--ink-2` | `#0c0f19` / `#121626` | 卡片、抽屉、行内代码底色 |
| `--line` / `--line-2` | 蓝灰半透明 | 分隔线 / 边框与按钮描边 |
| `--fg` | `#e7eaf4` | 标题、重要文字 |
| `--text` | `#cfd4e3` | 正文 |
| `--mute` | `#7f88a3` | 次要文字、日期、说明 |
| `--cyan` | `#7cecff` | 链接、当前位置、数值 |
| `--violet` | `#a88bff` | 标签（#tag）、渐变终点 |

青色和紫色是仅有的两个强调色，渐变只从青到紫。对比度都达到 WCAG AA：
正文 13.7:1，次要文字 5.7:1。

## 字体

五个字体家族各管一件事，不交叉使用。

| 角色 | 变量 | 字体 | 用在 |
| --- | --- | --- | --- |
| 中文标题 | `--f-cn-display` | Noto Serif SC 700/900 | 分区大标题、文章标题、正文小标题 |
| 英文副标题 | `--f-poem` | Cormorant Garamond 斜体 | 中文标题下的小字、口号 |
| 展示数字与字标 | `--f-display` | Big Shoulders Display | 统计数字、年份、分类名、字标 |
| 正文 | `--f-body` | 系统中文字体（苹方、微软雅黑等） | 文章、摘要、说明 |
| 标签与元信息 | `--f-mono` | JetBrains Mono | 日期、英文标签、代码、小眉标 |

字体全部放在站内，不依赖境外域名：

- 三个英文字体是 `source/fonts/` 里的文件（拉丁字符子集，可变字重）。
- Noto Serif SC 只用于标题，由 `scripts/signal-fonts.js` 在每次构建时收集
  所有标题里出现的字，只下载这些字形，生成 `/fonts/display.css`。新文章的标题
  会自动包含在内，不需要手动处理。
- 本地构建连不上 Google 时，构建日志会给出提示，标题字体改为运行时从 Google
  加载，线上构建（GitHub Actions）不受影响。

## 文字规则

- **斜体只给英文。** 中文字体没有斜体，浏览器硬拉斜会像排版错误。
- **大标题用中文，下面配一行英文斜体小字。** 例如 札记 *every entry, by date*。
  新页面在 front-matter 里写 `subtitle:` 即可得到同样的页头。
- **标签用英文**（`pwn`、`ret2text`），文章内容用中文。
- 小眉标、计数、日期用等宽字体，英文大写，字距加宽（`letter-spacing: .1em` 到 `.2em`）。

## 字号阶梯

| 层级 | 大小 |
| --- | --- |
| 首页分区标题 | `clamp(46px, 7vw, 100px)`，900 |
| 页面标题（归档、标签等） | `clamp(40px, 6vw, 72px)`，900 |
| 文章标题 | `clamp(34px, 5vw, 62px)`，900 |
| 英文副标题 | 22px（首页 `clamp(20px, 2.4vw, 30px)`） |
| 正文 H2 / H3 | 26px / 20px，700 |
| 正文 | 16.5px，行高 1.9（手机 16px） |
| 元信息、眉标 | 11 到 13px 等宽 |

文章正文栏宽 `--post-w: 760px`，一行大约 40 个汉字。

## 十六进制装饰

十六进制和寄存器名是 SIGNAL 的标志，但它们会和真实信息抢注意力。规则：

1. 优先用在映射真实含义的地方，例如页头的阅读偏移 `OFFSET 0x0404 / 0x1EA8`。
2. 每个组件最多一处。
3. 纯装饰的部分要对读屏软件隐藏：元素加 `aria-hidden="true"`，CSS 生成的
   内容写成 `content: attr(data-loc) / "";`。
4. 装饰性的地址用暗色（如首页札记列表的地址 `#4b5372`），不用强调色。

现在保留的有：页头的 RIP / OFFSET 读数、正文 H2 上方的 `loc_` 小标、
首页札记列表的段地址、年鉴的寄存器名（RAX 等）。鼠标指着时才出现的有：
札记行的断点和页头的 `JMP` 读数、年鉴每一格的十六进制和二进制值。

## 动效与交互

- 鼠标交互保持轻：只回应鼠标正指着的东西，平时看不出来。光标本身之外，不再加跟着鼠标跑的东西（圆环、小球）。
  现有的几处：

  | 位置 | 鼠标指着时 | 代码 |
  | --- | --- | --- |
  | 首屏字标 | 整体轻微视差；附近的粒子被推开，再弹回（磁铁） | `signal.js` |
  | 首页札记 | 行首出现断点，段地址变亮，页头读数跳成 `JMP <地址>` | `signal.js`、`signal-home.styl` |
  | 年鉴 | 显示这个数的十六进制和二进制 | `signal-home.js`、`signal-home.styl` |
  | 页脚谐波图 | 左右调 f₂（±0.04），上下调相位（±π/4），移开后回到原样 | `signal.js` |
  | 文章代码 | 相同的地址或名字一起高亮（见[文章渲染增强](article-rendering.md)） | `post-enhancements.js` |

  这些只对鼠标生效，触屏上没有。开启「减少动态效果」时磁铁和调频关闭，其余几处
  只是颜色和文字变化，照常工作，没有过渡动画。
- **光标**：示波光点，由 `signal-cursor.js` 画在一层画布上。平时是一个发光的点，
  移动时拖一小段褪色的余辉；能点的地方四个角展开框住它（整行、大图这类很大的目标
  只在鼠标周围框一个小框）；文字上拉成和字一样高的竖线；按下时荡开一圈波纹。
  光点就画在鼠标的真实位置上，点哪里就是哪里。
  - 只对鼠标生效，触屏和「强制颜色」（高对比度）模式下不加载。
  - 脚本看到鼠标移动后才隐藏系统光标。在那之前、脚本没加载成功时，显示换过图案的
    系统光标（`source/images/cursor/`：细箭头、四角锁定框、I 形）。
  - 评论区（giscus 的 iframe）和滚动条上用系统光标。
  - 开启「减少动态效果」时没有余辉、波纹和过渡，形状照常变化。
  - 新组件需要「可点」的光标时写 `cursor: var(--cursor-pointer, pointer)`，不要直接
    写 `pointer`；如果它不是链接或按钮，把选择器加进 `signal-cursor.js` 的
    `CLICKABLE`，光点才会框住它。
- **不打断滚动**：不做滚动时把区块钉住（sticky、pin）的设计。
- 开场动画每个浏览器标签页只播一次，可以跳过。
- 尊重系统「减少动态效果」设置。

## 组件约定

- **页脚（Coda）**：首页是完整版（空心 SILEN1 + 谐波图），其他页面只留谐波图、
  运行时间和版权行。
- **文章目录**：宽屏是正文左侧一条细长的目录，常驻；窄屏收进浮动按钮打开的抽屉。
  侧栏只放目录，没有「站点概览」。
- **代码块**：shell 会话（`bash`、`sh`、`console` 等）显示为终端：`$` 提示符代替
  行号；紧跟其后的 `text` 代码块是它的输出，合并进同一个框，复制按钮只复制命令。
  横向放不下时右边缘渐隐。写法见 [文章渲染增强](article-rendering.md)。
- **图标**：只用 `source/css/icons.css` 里的内联 SVG 图标，不加载 Font Awesome。
  需要新图标时在那里加一行。
- **空状态**：内容少时不显示需要数量才有意义的模块。远征路线至少 2 篇才画图，
  年鉴的标签光谱至少 5 篇才出现（`scripts/signal-home.js` 里的 `ROUTE_MIN`、`SPECTRUM_MIN`）。
- **分享卡片**：`source/images/og-card.png`（1200×630），全站默认使用。

## 暗室（隐藏日记）

日记写在一个文件 `source/_diary.md` 里：每条是一个 `## 2026-10-24 22:30` 日期行
（时间可省），下面一句话或一段话，没有标题。文件名以 `_` 开头，Hexo 不会把它当成
页面或文章，所以不进首页、札记、分类、标签、搜索、RSS 和 sitemap；
`scripts/signal-diary.js` 读它，生成带 `noindex` 的 `/0x7f/`，全文从新到旧铺开。
唯一入口是每篇文章末尾那行几乎看不见的 `EOF · 0x7f`。不要在 robots.txt 里写这个
路径，那等于公开告诉别人。
