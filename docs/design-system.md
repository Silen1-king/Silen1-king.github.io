# SIGNAL 设计规范

博客的视觉主题叫 SIGNAL，「从噪声里找信号」。2026-11 起的版本叫「静夜」：
整站只讲一件事，**一条信号线，和一片安静的夜**。
这一页记录已经定下来的规则，以后加页面、加组件时照着做，避免各写各的。

## 先读这三条

1. **一个比喻。** 全站只有「信号线 + 静夜」。不再加第二套比喻（城市、霓虹、
   地铁、调试器读数、内存地址都已经删掉，不要加回来）。
2. **加一删一。** 每加一个新的视觉元素（一种装饰、一种动效、一种颜色、一种字号），
   先删掉一个旧的。说不出删哪个，就不加。
3. **装饰让路给内容。** 页面上的字要么是内容，要么是导航。只为好看而存在的
   文字（假地址、假读数、英文眉标）不写。

## 信号线

同一条线从首页走到每篇文章的结尾，颜色都是 `--signal-line`（青到紫，两端淡出）：

| 位置 | 样子 |
| --- | --- |
| 首页首屏 | 字标下面一条缓缓起伏的波 |
| 页面和文章标题下 | 一条平的细线 |
| 文章阅读进度 | 页头底边，读到哪亮到哪 |
| 文章结尾 | 一段衰减的波，慢慢变平，月亮停在线的尽头 |
| 页脚 | 顶边一条平线：信号归于平静 |

需要分隔时用 `--line` 的发丝线；需要强调「这是一段的开始或结束」时才用信号线。
一屏里最多出现一条信号线。

## 月亮

月亮只出现在两个地方：首页首屏（字标旁，滚过首屏就淡出），和每篇文章的结尾
（信号线的尽头）。404 和暗室把它染成自己的颜色。别的页面没有月亮，也没有
别的背景图：底色是 `--void` 加顶部一点点蓝。

样式都在 `source/_data/signal-*.styl`：

| 文件 | 管什么 |
| --- | --- |
| `signal-base.styl` | 颜色与字体变量、页头、页脚（Coda）、侧栏目录、浮动按钮 |
| `signal-home.styl` | 首页：首屏和札记列表 |
| `signal-lists.styl` | 疆域的分类列表 |
| `signal-article.styl` | 文章页：标题、正文、代码块、评论 |
| `signal-pages.styl` | 归档、分类、标签、学习路线、404 |

样式写在 `@css { }` 里，否则 Stylus 会改写 `min()`、`max()`、`clamp()`。

## 颜色

只用 `:root` 里的变量，不在组件里写新的颜色值。

| 变量 | 值 | 用途 |
| --- | --- | --- |
| `--void` | `#05060b` | 页面底色 |
| `--ink` / `--ink-2` | `#0c0f19` / `#121626` | 卡片、抽屉、行内代码底色 |
| `--line` / `--line-2` | 蓝灰半透明 | 分隔线 / 边框与按钮描边 |
| `--fg` | `#e7eaf4` | 标题、重要文字 |
| `--text` | `#cfd4e3` | 正文 |
| `--mute` | `#7f88a3` | 次要文字、日期、说明 |
| `--cyan` | `#7cecff` | 链接、当前位置、数值 |
| `--violet` | `#a88bff` | 信号线的终点 |

青色和紫色是仅有的两个强调色，渐变只从青到紫，而且只用在信号线和首页口号上。
标题不发光（不加 `text-shadow` 霓虹效果），标签用 `--mute`，指着时才变青。
`--green`、`--rose`、`--heat` 只在文章正文里表达含义（提示框、diff、终端）。
红色 `#ff2b4f` 只给 404，琥珀色只给暗室。对比度都达到 WCAG AA：
正文 13.7:1，次要文字 5.7:1。

## 字体

五个字体家族各管一件事，不交叉使用。

| 角色 | 变量 | 字体 | 用在 |
| --- | --- | --- | --- |
| 中文标题 | `--f-cn-display` | Noto Serif SC 700/900 | 分区大标题、文章标题、正文小标题 |
| 英文副标题 | `--f-poem` | Cormorant Garamond 斜体 | 中文标题下的小字、口号 |
| 字标与年份 | `--f-display` | Big Shoulders Display | SILEN1 字标、归档年份、404 |
| 正文 | `--f-body` | 系统中文字体（苹方、微软雅黑等） | 文章、摘要、说明 |
| 代码与元信息 | `--f-mono` | JetBrains Mono | 代码、日期、标签 |

字体全部放在站内，不依赖境外域名：

- 三个英文字体是 `source/fonts/` 里的文件（拉丁字符子集，可变字重）。
- Noto Serif SC 只用于标题，由 `scripts/signal-fonts.js` 在每次构建时收集
  所有标题里出现的字，只下载这些字形，生成 `/fonts/display.css`。新文章的标题
  会自动包含在内，不需要手动处理。
- 本地构建连不上 Google 时，构建日志会给出提示，标题字体改为运行时从 Google
  加载，线上构建（GitHub Actions）不受影响。

## 文字规则

- **斜体只给英文。** 中文字体没有斜体，浏览器硬拉斜会像排版错误。
- **大标题用中文，下面配一行英文斜体小字。** 例如 札记 *every entry, by date*。
  新页面在 front-matter 里写 `subtitle:` 即可得到同样的页头。
- **标签用英文**（`pwn`、`ret2text`），文章内容用中文。
- 等宽字体只给代码、日期和标签。不再写大写加宽字距的英文眉标
  （`DISCUSSION`、`RELATED` 这类），小标题旁要配英文就用斜体小字。

## 字号阶梯

| 层级 | 大小 |
| --- | --- |
| 页面标题（归档、标签等） | `clamp(40px, 6vw, 72px)`，900 |
| 文章标题 | `clamp(34px, 5vw, 62px)`，900 |
| 英文副标题 | 22px（首页 `clamp(20px, 2.4vw, 30px)`） |
| 正文 H2 / H3 | 26px / 20px，700 |
| 正文 | 16.5px，行高 1.9（手机 16px） |
| 文末小标题（继续阅读、评论） | 24px，700 |
| 元信息 | 12 到 13px 等宽 |

文章正文栏宽 `--post-w: 760px`，一行大约 40 个汉字；其他页面栏宽
`--page-w: 960px`，都居中。

## 动效与交互

- 鼠标交互保持轻：只回应鼠标正指着的东西，平时看不出来。光标本身之外，不再加跟着鼠标跑的东西（圆环、小球）。
  现有的几处：

  | 位置 | 鼠标指着时 | 代码 |
  | --- | --- | --- |
  | 首屏字标 | 整体轻微视差；附近的粒子被推开，再弹回（磁铁） | `signal.js` |
  | 列表行、链接 | 标题变青 | 各 `.styl` |
  | 文章图片 | 平时压暗一成，指着时恢复原亮度 | `signal-article.styl` |
  | 文章代码 | 相同的地址或名字一起高亮（见[文章渲染增强](article-rendering.md)） | `post-enhancements.js` |

  这些只对鼠标生效，触屏上没有。开启「减少动态效果」时磁铁关闭，其余几处
  只是颜色变化，照常工作，没有过渡动画。
- **一条曲线，两个速度。** 过渡统一写 `var(--t-fast) var(--ease)`（0.2 秒，
  指着、聚焦）或 `var(--t-slow) var(--ease)`（0.6 秒，出现、消失）。不在组件里
  写新的时长和曲线。
- **滚动出现的只有文章结尾**：信号线画出来，月亮浮现（CSS 滚动时间线，
  不支持的浏览器直接显示）。别处不做滚动触发的入场动画。
- **光标**：示波光点，由 `signal-cursor.js` 画在一层画布上。平时是一个发光的点，
  移动时拖一小段褪色的余辉；能点的地方四个角展开框住它（整行、大图这类很大的目标
  只在鼠标周围框一个小框）；文字上拉成和字一样高的竖线；按下时荡开一圈波纹。
  光点就画在鼠标的真实位置上，点哪里就是哪里。
  - 只对鼠标生效，触屏和「强制颜色」（高对比度）模式下不加载。
  - 脚本看到鼠标移动后才隐藏系统光标。在那之前、脚本没加载成功时，显示换过图案的
    系统光标（`source/images/cursor/`：细箭头、四角锁定框、I 形）。
  - 评论区（giscus 的 iframe）和滚动条上用系统光标。
  - 开启「减少动态效果」时没有余辉、波纹和过渡，形状照常变化。
  - 新组件需要「可点」的光标时写 `cursor: var(--cursor-pointer, pointer)`，不要直接
    写 `pointer`；如果它不是链接或按钮，把选择器加进 `signal-cursor.js` 的
    `CLICKABLE`，光点才会框住它。
- **不打断滚动**：不做滚动时把区块钉住（sticky、pin）的设计。
- 开场动画每个浏览器标签页只播一次，可以跳过。
- 尊重系统「减少动态效果」设置。

## 组件约定

- **页脚（Coda）**：顶边一条平的信号线，下面一行：*Coda.*、已运行天数
  （打开页面时算一次，不跳秒）、访客数（拿到数字才显示）、版权。
- **首页**：首屏之后只有札记列表（最近几篇），不重复远征、疆域的内容。
- **札记行**：日期、标题、摘要、最多两个标签、分类和阅读分钟。没有地址和编号。
- **远征**：顶部一份路线目录（路线名 + 篇数，发丝线分隔，点击跳到该路线）；
  下面每条路线一张安静的卡片，标题加篇数，下面是有序的文章列表。
- **文章结尾**：信号线和月亮，然后依次是标签、上一篇/下一篇、继续阅读、评论。
- **文章图片**：发丝边框、4px 圆角、压暗一成。只有一行的代码块不显示标题栏和行号。
- **文章目录**：宽屏是正文左侧一条细长的目录，常驻；窄屏收进浮动按钮打开的抽屉。
  侧栏只放目录，没有「站点概览」。
- **代码块**：shell 会话（`bash`、`sh`、`console` 等）显示为终端：`$` 提示符代替
  行号；紧跟其后的 `text` 代码块是它的输出，合并进同一个框，复制按钮只复制命令。
  横向放不下时右边缘渐隐。写法见 [文章渲染增强](article-rendering.md)。
- **图标**：只用 `source/css/icons.css` 里的内联 SVG 图标，不加载 Font Awesome。
  需要新图标时在那里加一行。
- **分享卡片**：`source/images/og-card.png`（1200×630）全站默认使用；每篇文章
  另有一张（`source/images/og/`，`node tools/og-cards.js` 生成）：标题、信号线、
  线尽头的月亮。

## 漫游与友链

两个链接页由 `scripts/signal-links.js` 生成，内容只改数据文件：

- 漫游 `/wander/`：`source/_data/wander.yml`，不分组，每个网站一条独立链接（`name`、`url`，可选 `description`）。
- 友链 `/friends/`：`source/_data/friends.yml`，每人 `name`、`url`，可选 `description`、`avatar`。
  头像必须放在站内 `source/images/friends/`（CSP 不加载外站图片），没有头像显示名字首字母。
  友链还没有人时，导航栏里那一行在 `_config.next.yml` 中注释掉，有人后再打开。

## 暗室（隐藏日记）

日记写在一个文件 `source/_diary.md` 里：每条是一个 `## 2026-10-24 22:30` 日期行
（时间可省），下面一句话或一段话，没有标题。文件名以 `_` 开头，Hexo 不会把它当成
页面或文章，所以不进首页、札记、分类、标签、搜索、RSS 和 sitemap；
`scripts/signal-diary.js` 读它，生成带 `noindex` 的 `/0x7f/`，全文从新到旧铺开。
唯一入口是每篇文章末尾那行几乎看不见的 `EOF · 0x7f`。不要在 robots.txt 里写这个
路径，那等于公开告诉别人。

## 四个导航页（札记 / 远征 / 疆域 / 漫游）

四页用同一个页头：中文标题、英文斜体副标题、一句说明、一条信号线。正文都是
安静的列表，行与行之间用发丝线分隔，指着时标题变青。四页不各用一种颜色，
也没有各自的装饰。
